# 財務会計事務 学習アプリ

自治体の財務会計事務(起債・予算・決算)を、クイズ・手順ガイド・用語集で学べる個人学習用のWebアプリです。

**アプリを開く:** https://itta131313-spec.github.io/zaimukaikei_study_app/

## 開発用コマンド

```
npm install      # 初回のみ
npm run dev      # 開発用サーバーを起動
npm run build    # 公開用にビルド
```

本アプリの内容は一般的な自治体財務会計知識をもとにした学習用コンテンツです。実際の事務処理にあたっては、所属団体の例規・マニュアル等をご確認ください。
